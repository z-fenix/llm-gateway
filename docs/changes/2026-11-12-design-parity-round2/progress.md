## 证据与决策

- 初始基线：381 项测试通过。新增 foundation 测试先红后绿。
- 七个页面回归先复现失败，再实现；旧 UI 查询迁移为新真实入口，API payload 断言保留。
- 自审发现并复现后修复：空模型失败回退、刷新焦点、键盘选项滚动、主题保存失败镜像、知识库新建页脚、缓存单位与真实密钥前缀。
- 浏览器首轮 104 场景，8 个驱动断言失败：4 个在 React 更新完成前同步读取，4 个误用“应用”定位实际的“保存渠道”。修正驱动等待与按钮名称后，140 场景通过；保留 `acceptance-initial.json`。没有因此回退产品语义。
- Ruling: Settings 完整 CLI 编辑器保持页内编辑 — 实际结构不是弹窗，无需套 DialogBody — 若后续改成模态需另行分离头/正文/页脚。
- Ruling: 会话 TOOL 不伪造 READ 等工具名、不引入 Markdown/HTML 渲染 — 当前 API 只给 role/content/ts — 保留原文而非富文本预览。
- Ruling: 密钥前缀来自实际值而非设计示例 — 不改变真实凭据含义 — 示例截图前缀可能随夹具不同。
- Ruling: 验收使用独立隔离 Chrome 与只读合成 bridge — 不执行真实写入，不把模拟验收当原生 Tauri 端到端 — 原生系统交互和真实后端未验证。
- Final review: self-review（按约束不使用代理）；无独立第二位审查者，不能称为独立代码审查。

最终结果：40 个测试文件、426 项测试通过；typecheck、renderer build、diff --check 通过。144 组浏览器验收通过，运行时异常及整页/主内容/弹窗横向溢出均为 0；含模型键盘选择。600px 矮窗的长渠道正文滚动 1067/1427px 时，标题位移为 0，保存按钮 bottom=545px。构建仅保留 966.85kB JS chunk 警告。
