## 公共结构与交互

- `PageHeader` 使用 `PageNavigation` context：资源和记录页提供分组标题与页签，子页保留操作按钮；正常内容页面只有一个 h1，标题位于页签前。
- 移除标题与页面容器的重复垂直间距，统一 24px 区块间距、16px 卡片圆角、32px 桌面内容边距。
- ≥1280px 使用 216px 侧栏；768–1279px 为 72px 图标导航；手机使用原有抽屉导航。保留跳过导航、焦点管理、Escape 和路由切换关闭。
- 补齐表面、信息、弱化颜色和等宽字体 token；页面状态色使用语义类。趋势图仍保留 Tooltip、键盘层和数据表视图，基础三色已运行调色校验。
- 表单复用 `FormField`、`FormFooter`、`SecretInput` 和 `useFormValidation`：初始无行内错误，无效时禁用提交，失焦后显示字段错误，处理中阻止重复提交。
- 修复删除最后一个模型不显示校验提示、Skills `mcpServers` 字段引用、缺失 `STATUS_OPTIONS` 导出。
- 自审补充并修复：共享壳层监听刷新事件；Prompt 正文保存中禁止继续输入，避免保存完成覆盖新编辑；手机确认弹窗按钮保留间距。对应回归测试均观察到失败后修复通过。

## 执行决定及边界

1. 使用共享标题 context，而非复制资源/记录标题。代价是子页标题展示依赖分组上下文；单 h1、顺序和直接渲染子页均有测试。
2. 使用独立开发代理，不修改生产调用路径。代价是浏览器验证不能证明原生桥、真实连接与文件写入正确，需在原生环境另行验收。
3. 保留设计未绘制的旧功能，收纳到规则管理、更多筛选、清理、库设置、本地 Skills 发现及全部设置。代价是较纯设计稿多出少量二级入口，不以删除功能换取表面一致。
4. 按批准方式在当前会话顺序实施、不使用多代理和 worktree；最终进行了作者自审，不是独立审查。

未执行真实的启用模板、同步 Skills、写 CLI、清空日志等操作。原生端口重启、真实 MCP 握手、真实渠道测试、系统剪贴板和用户文件备份仍需在 Tauri 环境验证；单元测试中的 mock 不替代这些验证。
